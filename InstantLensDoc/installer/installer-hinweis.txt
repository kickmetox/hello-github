InstantLens Doc 2.6.27 — Installation

Startmenü: Gruppe „InstantLens Doc“ mit Programm, optional Keygenerator, INFO und Deinstallieren.

Desktop-Verknüpfung: optionale Checkbox im Installer-Assistenten
  (Task „desktopicon“, Flags checkedonce — Standard beim ersten Install aktiv, abwählbar).
  Ohne Haken: kein Desktop-Icon; Startmenü unabhängig über Task „startmenu“.

64-Bit: Installer läuft im 64-Bit-Modus (ArchitecturesInstallIn64BitMode=x64compatible).
  Empfohlen: 64-Bit-Python 3.10+ (Python-Layout) bzw. gebündelte x64-EXE.

Neu in 2.6.27 (Polish):
- Sync-Flow: sync-ild.ps1 -BuildInstaller (optional Setup.exe nach Sync)
- Nach Sync: install-ild.ps1 (Shortcuts) · build-windows-installer.ps1 (Setup.exe)
- Hilfe/Info: Installer · Keygen · Scripting vervollständigt
- Mausrad Text/Word-Suite: Trackpad + Rad · Shift→horizontal · Zeilennummern/Minimap

Basis 2.6.26:
- Installer-Pfad gehärtet: Version aus VERSION.txt, Preflight, CustomMessages DE/EN
- Konsolidierung 2.6.20–2.6.25 (Stylus, Outline, Hooks, Telemetrie, 3D, Hyperlinks/EPUB, Review)

Keygenerator (wenn IncludeKeygen=1):
- Python-Layout: Startmenü → Keygenerator → {app}\run-keygen.bat
- EXE-Layout: Startmenü → Keygenerator → {app}\InstantLensKeygen.exe
  (Datei liegt im Installationsordner neben InstantLensDoc.exe)

Deinstallation: Startmenü „InstantLens Doc deinstallieren“ oder Systemsteuerung / Apps.

Build (Windows x64 + Inno Setup 6):
  powershell -ExecutionPolicy Bypass -File .\scripts\build-windows-installer.ps1
  # oder nach Sync:
  powershell -ExecutionPolicy Bypass -File .\sync-ild.ps1 -BuildInstaller -SkipStart
