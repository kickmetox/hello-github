Startmenue: Gruppe "InstantLens Doc" mit Programm, optional Keygenerator, INFO und Deinstallieren.

Desktop-Verknuepfung: optionale Checkbox im Installer-Assistenten
  (Task "desktopicon", Flags checkedonce - Standard beim ersten Install aktiv, abwaehlbar).
  Ohne Haken: kein Desktop-Icon; Startmenue unabhaengig ueber Task "startmenu".

64-Bit: Installer laeuft im 64-Bit-Modus (ArchitecturesInstallIn64BitMode=x64compatible).
  Empfohlen: 64-Bit-Python 3.10+ (Python-Layout) bzw. gebuendelte x64-EXE.

Keygenerator (wenn IncludeKeygen=1):
- Python-Layout: Startmenue -> Keygenerator -> {app}\run-keygen.bat
- EXE-Layout: Startmenue -> Keygenerator -> {app}\InstantLensKeygen.exe
  (Datei liegt im Installationsordner neben InstantLensDoc.exe)

Deinstallation: Startmenue "InstantLens Doc deinstallieren" oder Systemsteuerung / Apps.

Build (Windows x64 + Inno Setup 6):
  powershell -ExecutionPolicy Bypass -File .\scripts\build-windows-installer.ps1
