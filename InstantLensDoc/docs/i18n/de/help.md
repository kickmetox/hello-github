# InstantLens Doc — Hilfe

Version **2.6.18**.

## Sprache

Extras → Einstellungen → **Oberflächensprache**: Deutsch, English, Français, Русский, Español, 中文, Português, العربية, Italiano.
Die Wahl wird gespeichert. Arabisch aktiviert RTL wo praktikabel.

## Module

- **Viewer** — PDF/Text, Zoom, Seiten
- **OCR** — Bild/PDF-Seite, Region, gesamtes PDF; optional Handschrift-PSM
- **Scan** — Import/Scanner + Tesseract
- **Annotationen** — Markieren, Stempel, Formen
- **Formulare** — AcroForm / Formulargenerator
- **Export** — HTML/DOCX/XLSX/PDF/TXT/RTF/JPG
- **Assistenten** — Erste Schritte, KI-Dokument-Wizards (kein freier Chat)
- **Einstellungen** — Theme, Sprache, OCR, Export, Autosave

## Handschrift

Extras → **Handschriftenerkennung…** oder OCR-Dialog → Handschrift-Modus (PSM). Basis-Hook ohne separates ML-Modell.
