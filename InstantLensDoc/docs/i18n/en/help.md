## Language

Extras → Settings → **UI language**: German, English, Français, Русский, Español, 中文, Português, العربية, Italiano.
The choice is persisted. Arabic enables RTL where practical.

## Modules

- **Viewer** — PDF/text, zoom, pages
- **OCR** — image/PDF page, region, entire PDF; optional handwriting PSM
- **Scan** — import/scanner + Tesseract
- **Annotations** — highlight, stamps, shapes
- **Forms** — AcroForm / form generator
- **Export** — HTML/DOCX/XLSX/PDF/TXT/RTF/JPG
- **Wizards** — Getting started, AI document wizards (no free chat)
- **Settings** — theme, language, OCR, export, autosave

## Handwriting

Extras → **Handwriting recognition…** or OCR dialog → handwriting mode (PSM). Basic hook, no separate ML model.
