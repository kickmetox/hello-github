# ShatuIDE Kurzanleitung

Version 1.0.0
Andreas Meyer, ame@sellerbach.de

Kurze Schritte für den Alltag. Die Befehlslisten stehen unter Hilfe.

## Start

1. ShatuIDE-Setup.exe starten und den Assistenten bis Fertigstellen durchgehen, oder ShatuIDE.exe direkt öffnen.
2. Python 3 muss auf dem Rechner installiert sein.
3. ShatuIDE.bat startet die Windows-Anwendung. py -3 shatuide.py öffnet dieselbe IDE im Browser.

## Neue Datei

1. Datei → Neue Datei oder die Schaltfläche Neu.
2. Art wählen: Python, PowerShell, Linux-Shell, Windows-Batch, CMD, JSON, HTML oder Text.
3. Namen eintragen. Aus hallo wird hallo.py, hallo.ps1, hallo.sh oder hallo.bat.
4. Anlegen öffnet die Datei. Strg+S speichert sie.
5. Strg+F5 führt sie aus. Eine Batch-Datei startet unter Windows mit cmd.exe.

## Öffnen und bearbeiten

1. Datei → Öffnen lädt eine vorhandene Datei. Datei laden übernimmt eine Datei in den Arbeitsordner.
2. Strg+X schneidet aus, Strg+C kopiert, Strg+V fügt ein.
3. Strg+F sucht in der Datei, Strg+H ersetzt darin.

## Ausführen und Debug

1. Ausführen → Syntax prüfen kontrolliert Python, PowerShell und die Linux-Shell.
2. F9 setzt einen Haltepunkt, F5 startet den Debug, F10 geht einen Schritt weiter.
3. Eine Fehlerzeile bleibt rot, bis ihr Text korrigiert ist oder ein Lauf ohne Fehler endet.

## PowerShell, Linux-Shell und Batch

1. PowerShell-Dateien enden auf .ps1, Linux-Shell auf .sh, Windows-Batch auf .bat oder .cmd.
2. Hilfe → Befehlslisten zeigt Erklärung, Syntax und ein Beispiel zu den häufigen Befehlen.
3. Erzeugen → Skript aus Abfrage baut ein fertiges Skript unter ausgabe/.

## Weitergeben

1. Hilfe → Anleitung und ANLEITUNG.md erklären die Bedienung für andere Nutzer.
2. Hilfe → Feature-Liste und FEATURE-LISTE.md nennen die Funktionen.
3. Speichern schreibt beide Dateien nach ausgabe/. ShatuIDE.zip enthält den kompletten Arbeitsordner.
