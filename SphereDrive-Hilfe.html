SphereDrive Hilfe

SphereDrive ist die Windows-Oberfläche für virtuelle Laufwerke und Ordnerverknüpfungen. Sie fasst subst, net use, mklink, New-PSDrive und mountvol in einem Fenster zusammen. Ein Ordner, ein Unterordner oder eine Freigabe erscheint damit wie ein eigenes Laufwerk, ohne dass die Dateien verschoben werden. Auf Windows 11 steht der Systemname in der Seitenleiste.

Menüleiste

  • Datei aktualisiert die Anzeige oder beendet das Programm.
  • Subst, net use, Verknüpfungen, PowerShell und Bereitstellung sind gleich aufgebaut: Seite öffnen, neu anlegen und trennen.
  • Das Menü net use enthält Seite öffnen, Freigabe verbinden, Ordner freigeben und Trennen.
  • Hilfe öffnet diesen Text, die Feature-Liste und die Dateien neben dem Programm.
  • Das Menü Sprache schaltet die Oberfläche um. Die Namen der Sprachen bleiben in der eigenen Sprache.

Kachelmenü

  • Die drei Punkte an einer Kachel öffnen Alle Möglichkeiten, net use, Im Explorer öffnen und, wenn erlaubt, Trennen.
  • net use auf einem echten Datenträger wie C: legt sich nicht über diesen Buchstaben. Es öffnet die Verbindung mit einem freien Buchstaben.

net use

  • Der Befehl lautet net use X: \\Computer\Freigabe.
  • Dauerhaft setzt /persistent:yes. Ohne diese Option gilt die Verbindung nur bis zum Abmelden.
  • Ein Kennwort wird nur für den Aufruf verwendet und nicht in der Konfiguration gespeichert.
  • Ein lokaler Ordner muss zuerst freigegeben sein. Danach verbindet net use \\Computer\Freigabename.
  • Freigabe verbinden öffnet den Dialog mit der Möglichkeit net use. Ordner freigeben wechselt auf die Seite Netzlaufwerke und zeigt dort das Freigeben eines Ordners.

Subst, Verknüpfungen, PowerShell und Bereitstellung

  • Subst hängt einen lokalen Ordner, auch einen Unterordner, als Laufwerksbuchstaben ein.
  • Verknüpfungen legen Junctions, symbolische Links und Hardlinks an. Entfernen löscht nur die Verknüpfung.
  • PowerShell legt ein New-PSDrive an, auf Wunsch im Profil. -Persist gilt nur für UNC-Pfade.
  • Bereitstellung hängt eine Partition oder eine VHD an einen Buchstaben oder einen leeren NTFS-Ordner. Die Datenträgerverwaltung öffnet diskmgmt.msc.

SphereDrive Help

SphereDrive is the Windows interface for virtual drives and folder links. It brings subst, net use, mklink, New-PSDrive and mountvol into one window. A folder, a subfolder or a share then appears as its own drive, without moving the files. On Windows 11 the system name is shown in the sidebar.

Menu bar

  • File refreshes the view or exits the program.
  • Subst, net use, Shortcuts, PowerShell and Mount follow the same shape: open the page, create, and disconnect.
  • The net use menu contains Open page, Connect share, Share a folder and Disconnect.
  • Help opens this text, the feature list and the files next to the program.
  • The Language menu switches the interface. Language names stay in their own language.

Tile menu

  • The three dots on a tile open All actions, net use, Open in Explorer and, when allowed, Disconnect.
  • net use on a real disk such as C: does not cover that letter. It opens the connection with a free letter.

net use

  • The command is net use X: \\Computer\Share.
  • Persistent sets /persistent:yes. Without that option the connection lasts only until logoff.
  • A password is used only for the call and is not stored in the configuration.
  • A local folder must be shared first. Then net use connects \\Computer\ShareName.
  • Connect share opens the dialog with net use selected. Share a folder switches to Network drives and shows how to share a folder.

Subst, shortcuts, PowerShell and mount

  • Subst mounts a local folder, including a subfolder, as a drive letter.
  • Shortcuts create junctions, symbolic links and hard links. Remove deletes only the shortcut.
  • PowerShell creates a New-PSDrive, optionally in the profile. -Persist applies only to UNC paths.
  • Mount attaches a partition or a VHD to a letter or an empty NTFS folder. Disk Management opens diskmgmt.msc.

Feature list

Drive mappings

  • Tiles or list, filter “Show all drives”
  • A click on a tile or on ··· opens the actions for that letter
  • Label, icon, Explorer and disconnect
  • Real disks are not covered by subst or net use

Folders and subfolders

  • A tree of a drive’s folders, further levels when expanded
  • A subfolder is mounted as its own drive
  • The same picker under Subst and as the target of a folder mount

subst

  • Local folders, including deep inside OneDrive, Google Drive or Dropbox
  • Persistent through startup and, with administrator rights, through DOS Devices
  • Recycle Bin through known-folder registration
  • Visibility for elevated programs through EnableLinkedConnections and a logon task

net use

  • UNC shares, persistent with /persistent:yes
  • Create and remove shares
  • Passwords are used for the call and are not stored

Shortcuts

  • mklink /J for junctions, /D for folder links, plus file symlinks and hard links
  • Remove deletes only the shortcut, not the target folder

PowerShell

  • New-PSDrive for the file system, registry, certificates and other providers
  • Optional in the PowerShell profile; -Persist only for UNC paths

Mount

  • A partition or VHD/VHDX on a letter or in an empty NTFS folder
  • Opens Disk Management (diskmgmt.msc)

Program

  • A comparison of which command is meant for which job
  • Work folder D:\AI_Temp\SphereDrive; a logo in that folder takes priority
  • Installer with embedded Python, restore at logon with --restore
  • Help inside the program and as SphereDrive-Hilfe.html next to the program
  • Feature list in the Help menu and as SphereDrive-Feature-Liste.txt
  • Usable in German, English, French, Spanish, Portuguese, Russian and Chinese

Subst. SphereDrive sets the label, icon, Recycle Bin and restore after reboot.

NAS, server or a folder that is already shared

net use. “Persistent” keeps the connection with /persistent:yes.

A folder in another place, without a new letter

Junction (mklink /J). To older programs it behaves like a physical folder.

New-PSDrive. Without a profile the drive exists only in the open session.

A real partition or VHD into an empty folder

A mount point. Or do the same step in Disk Management.

Uma pasta, uma subpasta ou uma partilha aparece então como unidade própria, sem mover os ficheiros. No Windows 11 o nome do sistema fica na barra lateral.

  • A mesma escolha em Subst e como destino de uma montagem de pasta

subst

  • Pastas locais, também no interior do OneDrive, Google Drive ou Dropbox

  • Criar e remover partilhas
  • As palavras-passe são usadas na chamada e não são guardadas

PowerShell

Montagem

  • Uma partição ou VHD/VHDX numa letra ou numa pasta NTFS vazia
  • Abertura da Gestão de discos (diskmgmt.msc)

Справка SphereDrive

SphereDrive — это интерфейс Windows для виртуальных дисков и ссылок на папки. Он собирает subst, net use, mklink, New-PSDrive и mountvol в одном окне. Папка, вложенная папка или общий ресурс выглядит как отдельный диск, файлы при этом не перемещаются. В Windows 11 имя системы показано на боковой панели.

Строка меню

  • «Файл» обновляет вид или закрывает программу.
  • Subst, net use, Ярлыки, PowerShell и Подключение устроены одинаково: открыть страницу, создать и отключить.
  • Меню net use содержит «Открыть страницу», «Подключить ресурс», «Открыть общий доступ» и «Отключить».
  • «Справка» открывает этот текст, список функций и файлы рядом с программой.
  • Меню «Язык» переключает интерфейс. Названия языков остаются на своём языке.

Меню плитки

  • Три точки на плитке открывают «Все действия», net use, «Открыть в проводнике» и, если можно, «Отключить».
  • net use на реальном диске вроде C: не закрывает эту букву. Он открывает подключение со свободной буквой.

net use

  • Команда: net use X: \\Компьютер\Ресурс.
  • «Постоянно» задаёт /persistent:yes. Без этого параметра соединение живёт только до выхода.
  • Пароль используется только для вызова и не сохраняется в конфигурации.
  • Локальную папку нужно сначала открыть для доступа. Затем net use подключает \\Компьютер\ИмяРесурса.
  • «Подключить ресурс» открывает диалог с выбранным net use. «Открыть общий доступ» переходит на сетевые диски и показывает общий доступ к папке.

Subst, ярлыки, PowerShell и подключение

  • Subst подключает локальную папку, в том числе вложенную, как букву диска.
  • Ярлыки создают точки соединения, символические и жёсткие ссылки. Удаление стирает только ярлык.
  • PowerShell создаёт New-PSDrive, по желанию в профиле. -Persist действует только для UNC-путей.
  • Подключение присоединяет раздел или VHD к букве или к пустой папке NTFS. Управление дисками открывает diskmgmt.msc.

Список функций

Назначения дисков

  • Плитки или список, фильтр «Показать все диски»
  • Щелчок по плитке или по ··· открывает действия этой буквы
  • Метка, значок, проводник и отключение
  • Реальные диски не закрываются через subst или net use

Папки и вложенные папки

  • Дерево папок диска, следующие уровни при раскрытии
  • Вложенная папка подключается как собственный диск
  • Тот же выбор в Subst и как цель подключения папки

subst

  • Локальные папки, в том числе глубоко в OneDrive, Google Drive или Dropbox
  • Постоянно через автозапуск и, с правами администратора, через DOS Devices
  • Корзина через регистрацию известной папки
  • Видимость для программ с повышенными правами через EnableLinkedConnections и задачу входа

net use

  • Ресурсы UNC, постоянно с /persistent:yes
  • Создавать и удалять общие ресурсы
  • Пароли используются для вызова и не сохраняются

Ярлыки

  • mklink /J для точек соединения, /D для ссылок на папки, а также символические ссылки на файлы и жёсткие ссылки
  • Удаление стирает только ярлык, не целевую папку

PowerShell

  • New-PSDrive для файловой системы, реестра, сертификатов и других поставщиков
  • По желанию в профиле PowerShell; -Persist только для UNC-путей

Подключение

  • Раздел или VHD/VHDX на букву или в пустую папку NTFS
  • Открытие управления дисками (diskmgmt.msc)

Глубокая папка проекта как диск

Subst. SphereDrive задаёт метку, значок, корзину и восстановление после перезагрузки.

SphereDrive 帮助

SphereDrive 是用于虚拟驱动器和文件夹链接的 Windows 界面。它把 subst、net use、mklink、New-PSDrive 和 mountvol 放在同一个窗口里。文件夹、子文件夹或共享会显示为独立驱动器，而文件并不移动。在 Windows 11 上，侧栏会显示系统名称。

菜单栏

  • “文件”用于刷新显示或退出程序。
  • Subst、net use、链接、PowerShell 和装载的结构相同：打开页面、新建和断开。
  • net use 菜单包含打开页面、连接共享、共享文件夹和断开。
  • “帮助”打开这段文字、功能列表以及程序旁边的文件。
  • “语言”菜单切换界面。语言名称始终使用各自的语言。

磁贴菜单

  • 磁贴上的三个点会打开全部操作、net use、在资源管理器中打开，以及在允许时断开。
  • 在 C: 这样的真实磁盘上使用 net use 不会盖住该盘符。它会用一个空闲盘符打开连接。

net use

  • 命令是 net use X: \\计算机\共享。
  • “永久”会设置 /persistent:yes。没有该选项时，连接只持续到注销。
  • 密码只用于本次调用，不会写入配置。
  • 本地文件夹必须先共享。然后 net use 连接 \\计算机\共享名。
  • “连接共享”会打开已选择 net use 的对话框。“共享文件夹”会转到网络驱动器页面，并显示如何共享文件夹。

Subst、链接、PowerShell 和装载

  • Subst 把本地文件夹（包括子文件夹）挂为驱动器号。
  • 链接用于创建 Junction、符号链接和硬链接。删除只去掉链接。
  • PowerShell 创建一个 New-PSDrive，可以选择写入配置文件。-Persist 只适用于 UNC 路径。
  • 装载把分区或 VHD 接到盘符或空的 NTFS 文件夹。磁盘管理会打开 diskmgmt.msc。

功能列表

驱动器映射

  • 磁贴或列表，筛选“显示所有驱动器”
  • 单击磁贴或 ··· 会打开该盘符的操作
  • 标签、图标、资源管理器和断开
  • 真实磁盘不会被 subst 或 net use 盖住

文件夹和子文件夹

  • 驱动器的文件夹树，展开后加载下一层
  • 子文件夹可以作为独立驱动器装入
  • 在 Subst 中以及作为文件夹装载目标时使用同一选择器

subst

  • 本地文件夹，包括 OneDrive、Google Drive 或 Dropbox 中较深的位置
  • 通过开机启动保持永久；有管理员权限时还通过 DOS Devices
  • 通过已知文件夹注册使用回收站
  • 通过 EnableLinkedConnections 和登录任务，让提升权限的程序也能看到

net use

  • UNC 共享，使用 /persistent:yes 保持永久
  • 创建和删除共享
  • 密码只用于本次调用，不会保存

链接

  • mklink /J 用于 Junction，/D 用于文件夹链接，以及文件符号链接和硬链接
  • 删除只去掉链接，不删除目标文件夹

PowerShell

  • New-PSDrive 用于文件系统、注册表、证书和其他提供程序
  • 可选写入 PowerShell 配置文件；-Persist 仅用于 UNC 路径

装载

  • 把分区或 VHD/VHDX 装到盘符或空的 NTFS 文件夹
  • 打开磁盘管理 (diskmgmt.msc)

程序

  • 比较哪种命令适合哪种用途
  • 工作文件夹 D:\AI_Temp\SphereDrive，该文件夹中的徽标优先
  • 安装程序内嵌 Python，登录时用 --restore 恢复
  • 程序内的帮助，以及程序旁边的 SphereDrive-Hilfe.html
  • 帮助菜单中的功能列表，以及 SphereDrive-Feature-Liste.txt
  • 可使用德语、英语、法语、西班牙语、葡萄牙语、俄语和中文

何时用哪个命令

把较深的项目文件夹作为驱动器

使用 Subst。SphereDrive 会设置标签、图标、回收站以及重启后的恢复。

NAS、服务器或已经共享的文件夹

使用 net use。“永久”通过 /persistent:yes 保留连接。

把文件夹放到另一处，而不占用新盘符

使用 Junction（mklink /J）。对旧程序来说，它表现得像一个物理文件夹。

仅在 PowerShell、注册表或证书中

使用 New-PSDrive。如果不写入配置文件，驱动器只存在于当前打开的会话中。

把真实分区或 VHD 装入空文件夹

使用装载点。也可以在磁盘管理中做同样的步骤。
